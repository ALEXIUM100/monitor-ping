 Monitor de Ping

Herramienta en Python para verificar el estado de hosts en una red.

¿Qué hace?
- Hace ping a una lista de hosts configurables
- Muestra si están activos o caídos
- Funciona en Windows, Linux y Mac

¿Cómo usarlo?
1. Instala Python 3
2. Edita la lista de `hosts` en `monitor.py`
3. Ejecuta: `python monitor.py`

Tecnologías
- Python 3
- Librerías: subprocess, platform, datetime
